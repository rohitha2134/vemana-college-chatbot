# Vemana Institute of Technology (Vemana IT) - Standalone LetseeAI Assistant Package

This is a completely standalone, exportable AI assistant project generated by LetseeAI.

## Architecture
- **Company AI Edge Directory**: `/ai-edge/`
  - `/ai-edge/knowledge/`: `company-profile.json`, `atomic-facts.json`, `knowledge-graph.json`, `manual-qa.json`
  - `/ai-edge/index/`: `semantic-index.json`, `entity-index.json`, `intent-index.json`
  - `/ai-edge/config/`: `ai-edge-config.json`, `answer-boundaries.json`, `source-provenance.json`
  - `/ai-edge/prompts/`: `system-instructions.txt`, `reasoning-prompt.txt`, `grounding-rules.txt`
  - `/ai-edge/runtime/`: `retrieval-engine.js`, `reasoning-engine.js`, `answer-validator.js`, `local-model-config.json`, `ai-edge-runtime.js`
- **Zero API Keys & Zero Backend**: No OpenAI, Gemini, Firebase, or external chat inference dependencies required.
- **Cross-Match & Anti-Hallucination Protected**: Strict boundary isolation guarantees no fabricated facts or leaked unrelated information.

## How to Deploy (Static Hosting)
1. Deploy this folder directly to any static web host:
   - **Netlify**: Drag and drop the folder in Netlify Drop.
   - **Cloudflare Pages**: Connect or upload as a static directory.
   - **Vercel**: Deploy as a static project.
   - **GitHub Pages**: Push to repository and enable GitHub Pages.
2. Note your deployed URL (e.g. `https://vemana-institute-of-technology-vemana-it-demo.netlify.app`).
3. Embed on the customer's existing website using the code in `embed-code.html`.
